# 哔哩哔哩 macOS 客户端

本仓库只提供安装包、SHA-256 校验文件和分发说明，不包含应用源码。

[下载最新版本](https://github.com/yume-shek/Bilibili-updates/releases/latest)

适用于 Apple 芯片 Mac，macOS 14 或更高版本。下载 DMG 后将“哔哩哔哩.app”拖入 Applications 文件夹。

0.1.4 起的公开安装包包含线程撕裂者（BTR）播放加速。海外用户可在设置中选择海外模式；大陆、海外和自定义节点目录均内置 estgcos，无需访问私有源码或自行编译。

新增独立侧栏/评论比例、字幕大小、可拖动评论宽度、UP主关注、本人硬币、蓝色评论链接、历史统计及关注排序。具体变化见各版本发布记录。

当前版本通过发布页手动下载并替换应用，不再自动检查、下载或安装更新。账号与偏好保存在使用者本机，安装包不包含登录资料。

应用采用 ad-hoc 本地签名，未进行 Developer ID 签名或 Apple 公证。若被 macOS 拦截，请在“系统设置 → 隐私与安全性”检查后选择“仍要打开”。

旧版本及其历史签名附件保留，升级与回退都可通过手动替换应用完成。
