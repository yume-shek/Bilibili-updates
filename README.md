# 哔哩哔哩 macOS 客户端更新

本仓库只提供安装包、SHA-256 校验文件和签名更新清单，不包含应用源码。

[下载最新版本](https://github.com/yume-shek/Bilibili-updates/releases/latest)

适用于 Apple 芯片 Mac，macOS 14 或更高版本。下载 DMG 后将应用拖入 Applications 文件夹。

从 0.1.1（20261112.2）开始，正式版通过本仓库检查更新。默认提醒安装；可在「设置 → 更新」开启静默下载、退出时安装。更新包和清单均使用 Ed25519 签名校验。

旧版没有更新入口或仍指向私有更新源时，请手动安装最新版本一次。账号与偏好保存在本机，不包含在安装包中。

应用采用 ad-hoc 签名，尚未进行 Apple 公证。
